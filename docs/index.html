FichaManual

Aplicación de escritorio para Windows que resume un manual largo (texto o PDF) y deja los datos importantes ordenados en una ficha clara.

Descarga

Descargar para Windows

Windows 10/11 · ZIP ~28 MB · No hace falta instalar Python

Instalación (3 pasos)

  1. Descomprime el archivo FichaManual-Setup.zip.
  2. Haz doble clic en FichaManual-Setup.bat.
  3. Abre FichaManual desde el Escritorio (o el Menú Inicio).

Luego: pega el texto del manual o abre un .txt / .pdf y pulsa Crear ficha.
