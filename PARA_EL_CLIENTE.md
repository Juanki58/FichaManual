# FichaManual — Instrucciones para el cliente

Hay **dos entregas distintas**:

| Plataforma | Qué recibirás | Estado |
|------------|---------------|--------|
| **Windows** | Archivo `FichaManual-Setup.zip` | Listo para probar hoy |
| **Android** | APK o enlace aparte | Se entrega aparte (ver `ANDROID.md`) |

---

## Windows (prueba inmediata)

### Requisitos

- Windows 10 o Windows 11
- **No hace falta** instalar Python ni nada más

### Pasos

1. **Descomprime** el archivo `FichaManual-Setup.zip` (clic derecho → Extraer todo…).
2. Entra en la carpeta y **haz doble clic** en `FichaManual-Setup.bat`.
3. Cuando termine la instalación, abre **FichaManual** desde el **Escritorio** (o el Menú Inicio).
4. En la app:
   - Pega el texto del documento o abre un archivo `.txt` o `.pdf` con texto seleccionable.
   - Pulsa **Crear ficha**.
   - Revisa la ficha. Puedes copiarla o guardarla como texto o Markdown.

### Desinstalar

Menú Inicio → carpeta **FichaManual** → **Desinstalar FichaManual**.
